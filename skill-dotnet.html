🔷 .NET

.NET is a free, open-source framework by Microsoft for building web apps, desktop apps, mobile apps, and cloud services, mainly using C#.

Key Concepts

  • C# Language — Primary language used in .NET
  • ASP.NET Core — Framework for building web apps and APIs
  • Entity Framework — ORM for database access
  • MVC Pattern — Model-View-Controller architecture
  • Dependency Injection — Managing object dependencies cleanly
  • NuGet — Package manager for .NET libraries
