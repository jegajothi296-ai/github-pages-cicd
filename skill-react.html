⚛️ React

React is a JavaScript library for building user interfaces, mainly for single-page applications. It lets you build reusable UI components.

Key Concepts

  • Components — Reusable building blocks of UI
  • Props — Passing data between components
  • State — Data that changes over time inside a component
  • Hooks — Functions like useState, useEffect for managing logic
  • JSX — HTML-like syntax used inside JavaScript
